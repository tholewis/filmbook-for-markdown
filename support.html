Frequently asked questions

What file types can Filmbook open?

Markdown files with the .md, .markdown, .mdown, or .mkd extension, as well as plain text files.

Can I edit documents in Filmbook?

No — Filmbook is a read-only viewer by design. It assumes your file is already finished and focuses entirely on presenting it beautifully, with no save dialogs, conflict warnings, or risk of accidental edits.

How do I change the theme, font, or text size?

Open Settings from the toolbar. Choose from five themes (Light, Dark, Sand, Water, Industrial) and a selection of serif, sans, and monospaced reading fonts, including Atkinson Hyperlegible for accessibility. Text size follows your device's Dynamic Type setting.

Does Filmbook work offline?

Yes. Documents are rendered entirely on-device. An internet connection is only needed if a document you open links to a remote image.

How do I print or export a PDF?

Use the share menu in the toolbar to print the current document or save it as a paginated PDF.

What platforms does Filmbook support?

iPhone, iPad, and Mac.
