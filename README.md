# Filmbook for Markdown

Marketing website for [Filmbook](https://github.com/tholewis), a read-only Markdown viewer for iPhone, iPad, and Mac. Built as a plain static site and hosted on GitHub Pages, primarily so there's a live Support URL and Privacy Policy URL for App Store Connect.

Live site: https://tholewis.github.io/filmbook-for-markdown/

## Structure

- `index.html` — product page
- `support.html` — support contact and FAQ
- `privacy.html` — privacy policy
- `assets/css/style.css` — styles (palette mirrors the app's own Light/Sand/Dark themes)
- `assets/fonts/` — Atkinson Hyperlegible (OFL), the same accessible typeface bundled in the app
- `assets/img/screenshots/` — real app screenshots, rendered from the app's own Markdown engine
- `assets/img/` — logo mark, favicons, and social preview image

No build step — just static HTML/CSS served directly by GitHub Pages.
